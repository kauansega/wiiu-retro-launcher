# wiiu-retro-launcher
A retro game launcher inspired by Wii U interface for PICO-8 games, built in Unity 6.3.

# 🎮 Wii U Style Retro Launcher & PICO-8 Frontend

Um launcher e frontend de jogos retro inspirado na interface do Nintendo Wii U, desenvolvido em **Unity 6.3** e **C#**.

## Sobre o Projeto
Este projeto foi desenvolvido por **Kauan Miguel Eugenio** como parte dos meus estudos de Ciência da Computação e desenvolvimento de jogos. O objetivo é integrar um ambiente com a estética nostálgica de canais e sons relaxantes do Wii U com emulação/leitura de jogos virtuais do PICO-8 e CHIP-8.

## Tecnologias Utilizadas
- **Engine:** Unity 6.3
- **Linguagem:** C#
- **Interface:** Unity UI (Canvas Scaler com responsividade)
- **Controle de Versão:** Git & GitHub

## Funcionalidades
- [x] Menu principal em grade (WaraWara Plaza estilo)
- [x] Áudio dinâmico com transições entre menu e canais
- [x] Tela de detalhes/canal do jogo com jingles exclusivos
- [x] Sistema de Conquistas (Pop-ups)
- [ ] Lojinha de downloads (Em breve)
